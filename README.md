## 📂 Projetos apresentados

### 1. Mika — Assistente Virtual

Assistente virtual em desenvolvimento, criado para auxiliar na organização de atendimentos por meio da integração entre WhatsApp, inteligência artificial, agenda e automações.

**Tecnologias:** n8n, Docker, PostgreSQL e Evolution API.

**Status:** Em desenvolvimento.

### 2. Calculadora de Consumo Elétrico

Aplicação desenvolvida em Python para estimar o consumo mensal de energia elétrica e o custo aproximado de utilização de eletrodomésticos, considerando sua potência e tempo de uso.

**Tecnologias:** Python.

🔗 [Acessar repositório](https://github.com/CarolF15/consumo-energia)

### 3. Agente de Automação

Projeto desenvolvido com Python que simula um agente para classificação de tarefas, organização de prioridades e geração de registros de execução.

**Tecnologias:** Python.

🔗 [Acessar repositório](https://github.com/CarolF15/agente-automacao-DIO)

## 💡 Desenvolvimento

O projeto foi desenvolvido utilizando HTML5 para estruturar o conteúdo, CSS3 para personalizar a apresentação visual e JavaScript para implementar interações e animações.

O Bootstrap foi utilizado como apoio na construção do layout responsivo e dos componentes de navegação.

Como recurso adicional, foram implementadas animações de entrada dos elementos conforme o usuário navega pela página, utilizando JavaScript e a API Intersection Observer, além de efeitos visuais de interação nos componentes.
